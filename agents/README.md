# Perfis de agente

Os arquivos desta pasta descrevem papéis que podem ser usados individualmente ou em conjunto. Eles não iniciam processos nem delegam tarefas por conta própria; a ferramenta ou a pessoa consumidora decide como selecionar e executar cada perfil.

## Catálogo

| Perfil | Quando selecionar |
| --- | --- |
| [Orchestrator](orchestrator.md) | Para enquadrar uma solicitação, selecionar especialistas e consolidar o resultado. |
| [Software Architect](software-architect.md) | Para avaliar requisitos, limites, contratos e trade-offs de uma solução. |
| [Implementer](implementer.md) | Para implementar uma mudança pequena e coesa seguindo as convenções existentes. |
| [Test Engineer](test-engineer.md) | Para definir testes de comportamento e riscos de regressão. |
| [Code Reviewer](code-reviewer.md) | Para procurar defeitos, regressões e problemas de legibilidade ou compatibilidade. |
| [Security Reviewer](security-reviewer.md) | Para avaliar riscos de segurança no escopo da mudança. |
| [Documentation Writer](documentation-writer.md) | Para alinhar documentação ao comportamento e aos comandos reais. |

Selecione também o guia aplicável em [`../stacks/`](../stacks/README.md). Leia primeiro as instruções locais do projeto consumidor; elas contextualizam o uso destes perfis.
